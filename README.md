Мост, который заводит **Gemini 3.x Flash** в [DSH](https://github.com/deepseek-ai/deepseek-harness) — или в любой другой клиент, говорящий на OpenAI. В комплекте: слой выхода в сеть для случаев, когда Гугл напрямую недоступен, плагин веб-поиска с настоящим кэшем и оверлей с квотой.

Без зависимостей. Node 20+. Два локальных порта.

```text
DSH / любой OpenAI-клиент
        │  POST /v1/chat/completions   (SSE)
        ▼
127.0.0.1:8787  мост ── переводит OpenAI ↔ Cloud Code, крутит аккаунты
        │  CONNECT-туннель
        ▼
127.0.0.1:8789  шим выхода ── выбирает канал, сохраняет SNI
        │
        ▼
эдж smart-DNS ──► Google Cloud Code ──► Gemini
```

## Зачем это нужно

Модель Antigravity не отдаётся обычным публичным API. Она живёт в транспорте Cloud Code: другой протокол, свой OAuth, хосты, которые в ряде стран блокируются целиком. DSH при этом говорит на OpenAI.

Этот проект — тот самый переходник, плюс всё, что нужно, чтобы он выживал в недружелюбной сети: маршрутизация каналов со сторожем, квота по нескольким аккаунтам и поиск, который не умирает после третьего запроса.

## Что реально даёт

**Полноценная поверхность OpenAI, а не тонкий прокси.**
Стриминг и обычные ответы, инструменты с `tool_choice` (`auto` / `none` / `required` / конкретная функция), изображения, `reasoning_content` для размышлений и блок usage с числом закэшированных токенов промпта — по нему видно, работает ли кэш вообще.

**Стриминг, похожий на печать, а не на загрузку.**
Гугл отдаёт ~25 токенов раз в ~300 мс; если пропускать как есть, текст падает лепёшками. Мост режет каждую порцию на мелкие дельты с ровным тактом (`30 мс`, `AG_PACE_MS`). Размышления уходят сразу, а не задерживаются до конца хода.

**Честные ошибки.**
Отклонённый запрос возвращается один раз, а не долбится трижды в ту же стену — повтор осмыслен только для `429` и `5xx`, поэтому только они и повторяются. `finish_reason` различает `length` (обрезано), `tool_calls` и `stop`, вместо того чтобы всегда врать `stop`.

**Отображение effort, которое ведёт себя монотонно.**
`reasoning_effort` переводится в бюджет размышлений, замерено: minimal → 0 токенов, medium → ~220, high → ~300–550. Учти связку с `max_tokens`: при маленьком потолке все уровни схлопываются, потому что бюджет размышлений резервирует себе место первым.

**Много аккаунтов на одном эндпоинте.**
Запросы ходят по кругу между сохранёнными аккаунтами; `/accounts` и `/limits` показывают почты и остаток квоты по моделям. Один мёртвый аккаунт не роняет мост.

**Слой выхода, который переживает смерть своих каналов.**
Там, где Гугл заблокирован, мост идёт через smart-DNS релеи: резолвер выдаёт адрес эджа, TCP идёт туда, SNI остаётся гугловым, настоящий сертификат проверяется до конца. Каналы перебираются цепочкой, а сторож раз в две минуты щупает живой канал настоящим TLS-рукопожатием — релей умеет принимать TCP вечно и никогда не завершать TLS, и ровно так один канал молча умер на три часа. Два провала — и маршрут уходит на следующий канал, который прошёл ту же пробу. Проба ограничена 6 секундами, чтобы мёртвый резолвер не растягивал вердикт до полутора минут. **Запросы сторожа не ждут**: у него свой сокет и свой таймер.

**Веб-поиск, который не душат до бесполезности.**
Плагин для DSH, регистрирует провайдера `web_search`: сначала API с ключами (Serper, Tavily, Brave, Google CSE, Exa), в конце DuckDuckGo — под кэшем на 10 минут, синглфлайтом, token bucket, детектором челленджа и кулдауном на 90 секунд. Бесплатный путь держится около 7–8 запросов в минуту (всплеск на два, потом по одному в восемь секунд); плагин построен вокруг этого потолка, а не делает вид, что его нет.

**Оверлей квоты и подрезка контекста.**
Два небольших плагина: панель с квотой по аккаунтам и проход `lean-context`, который заменяет старые результаты инструментов маркером, чтобы длинные сессии не тонули в собственной истории.

## Быстрый старт

### Если Гугл доступен напрямую

```bash
git clone https://github.com/<you>/gemini-to-dsh.git
cd gemini-to-dsh
AG_EGRESS=0 ./start.sh          # macOS / Linux
# или: set "AG_EGRESS=0" && bridge\start.cmd     (Windows)
```

`AG_EGRESS=0` вообще не поднимает шим — ни лишнего хопа, ни настройки каналов.

### Если нет

Запускай без этой переменной. Цепочка по умолчанию (`bezmezhau → geohideeu → geohide → magicdns → direct`) зашита в дефолты, так что первый запуск работает как есть; каналы со временем умирают — для этого и нужен сторож. Как добавить свой — [docs/channels.md](docs/channels.md):

```bash
cd bridge
node egress-ctl.mjs add mydns 203.0.113.10 203.0.113.11 --seeds=cloudaicompanion.googleapis.com
node egress-ctl.mjs use mydns
node egress-ctl.mjs check mydns
```

### Аккаунты

Мост переиспользует OAuth-токены, которые подписка Google AI Pro уже создала на машине (это доступ Cloud Code, а не ключ с бесплатного тарифа). Положи их туда, где мост их ждёт — `~/.gemini/oauth_creds.json` для первого аккаунта и `~/.gemini/dsh-bridge/accounts.json` для набора ротации — либо укажи другие пути через `AG_CREDS_FILE` / `AG_ACCOUNTS_FILE`. OAuth-клиент, которым эти токены обновляются, **в репозиторий не входит**: задай `AG_CLIENT_ID` и `AG_CLIENT_SECRET` или положи их в `~/.dsh/ag-oauth.json`.

```bash
cd bridge && node bridge.js
curl -s localhost:8787/limits -H 'authorization: Bearer local-bridge' | head
```

## Подключение к DSH

Провайдер смотрит на локальный порт. Минимальный патч профиля:

```yaml
# ~/.dsh/profiles/web/cordis.patch.yml
- id: agent-default-model
  config:
    provider: antigravity
    model: gemini-3.8-flash
    reasoningEffort: medium
```

Мост принимает любой `Authorization`, совпадающий с `AG_BRIDGE_SECRET` (по умолчанию `local-bridge`), поэтому в записи провайдера нужен именно такой bearer.

## Настройка

Всё через переменные окружения; полный список с дефолтами в комментариях — [`.env.example`](.env.example) (там всё, что читает сам мост). У плагинов есть свои — `AG_BRIDGE_URL`, `AG_EGRESS_URL`, `WARP_CLI` — они описаны в README каждого плагина. Главное:

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `AG_BRIDGE_PORT` | `8787` | Порт с OpenAI-совместимым API |
| `AG_BRIDGE_SECRET` | `local-bridge` | Bearer, который принимает мост |
| `AG_EGRESS` | `1` | `0` полностью выключает шим |
| `AG_EGRESS_PORT` | `8789` | Порт CONNECT-шима |
| `AG_EGRESS_FILE` | `~/.dsh/ag-egress.json` | Конфиг маршрутизации; дефолты зашиты |
| `AG_EGRESS_DNS_TTL` | `60000` | Кэш ответов резолвера |
| `AG_EGRESS_BUDGET` | `6000` | Бюджет одного CONNECT на все каналы |
| `AG_WATCHDOG_MS` | `120000` | Интервал сторожа |
| `AG_PACE_MS` | `30` | Такт выдачи текста; `AG_PACE=0` выключает |
| `AG_CLIENT_ID` / `AG_CLIENT_SECRET` | — | OAuth-клиент для обновления токенов |
| `DSH_SEARCH_CONFIG` | `~/.dsh/search.json` | Ключи для плагина поиска |

## Плагины

| Плагин | Что делает |
| --- | --- |
| [`web-search`](plugins/web-search/README.md) | Провайдер `web_search`: API с ключами → DuckDuckGo, с кэшем и пейсингом |
| [`quota-overlay`](plugins/quota-overlay/README.md) | Панель: аккаунты, квота по моделям, маршрут выхода |
| [`lean-context`](plugins/lean-context/README.md) | Заменяет старые результаты инструментов, чтобы сессии оставались дешёвыми |

Установка — положить папку в `~/.dsh/profiles/web/plugins/` и добавить строку в патч профиля:

```yaml
- insert:
    - id: web-search
      name: "./plugins/web-search/index.js"
```

## Тесты

```bash
cd bridge
npm test            # юнит + egress + интеграционные
npm run smoke       # четыре запроса (модели, текст, инструменты, стрим); нужен запущенный мост
```

Юнит- и интеграционные наборы самодостаточны: поднимают мок Cloud Code, поэтому упавший тест означает код, а не сеть. С egress иначе — он открывает настоящие TLS-соединения, чтобы проверить, что `probeChannel` отличает живой канал от мёртвого; для него нужна исходящая сеть, в изолированном CI он не пройдёт.

## Честные ограничения

- **Неофициальный транспорт.** Cloud Code — не публичный API; Гугл меняет его без предупреждения, и однажды мосту понадобится патч. Твой аккаунт, твой риск, твоя подписка.
- **Скорость ограничена моделью.** `gemini-3.8-flash` декодирует ~85–100 токенов/с на любом маршруте — четыре канала и direct, одно и то же число. `gemini-3-flash` примерно в 2.5 раза быстрее; узкое место — модель, а не сеть.
- **`gemini-3.8-flash` на части тарифов существует только как `-tiered`**; алиас разрешает это сам.
- **Размышления приходят двумя большими блоками**, поэтому сгладить их нельзя, не задержав ответ. Текст плавный, thinking — кусками.
- **Релеи — чужая инфраструктура.** Они видят SNI и объём, но не содержимое TLS. И умирают без предупреждения.
- **Инструменты заточены под Windows**: `start.cmd` и `install-autostart.ps1` — Windows, `start.sh` покрывает macOS/Linux, но автозапуск — нет.
